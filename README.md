# Aldora Compass Enterprise Native

Enterprise-grade compass and navigation web app with realtime GPS, Qibla, tracking, and PWA features.

## Features
- Realtime Compass
- GPS Navigation
- Qibla Direction
- Route Tracking
- GPX / KML Export
- Dark / Light Mode
- Offline Support
- PWA Ready
- Sensor Calibration
- Waypoint Navigation

## Technology
- HTML5
- CSS3
- JavaScript
- Geolocation API
- Device Orientation API
- Local Storage
